# 🚀 EUROTOUR Bot — запуск на хостинге

Весь бот — **один файл `s.py`**. Больше ничего не нужно.

---

## ⚠️ ГЛАВНОЕ — почему у вас стирались данные

База лежала **в папке с кодом**. При каждом перезапуске/редеплое хостинг
разворачивает код заново — и база исчезала вместе со всеми настройками.

**Решение:** подключить постоянный диск (volume) и указать путь к базе.

```
DB_PATH = /data/eurotour.db
```

Бот сам найдёт `/data`, `/var/data`, `/mnt/data`, если такой диск подключён.
Без постоянного диска данные будут теряться на **любом** хостинге — это не баг бота.

---

## 📋 Что нужно на хостинге

| Настройка | Значение |
|---|---|
| **Start command** | `python3 s.py` |
| **Build command** | *не нужен* — скрипт ставит библиотеки сам |
| **Постоянный диск** | обязательно, точка монтирования `/data` |
| **Переменная `DB_PATH`** | `/data/eurotour.db` |
| **Переменная `BOT_TOKEN`** | ваш токен *(или уже вписан в код)* |
| **Тип сервиса** | Worker / Background (не Web) |

Если хостинг требует именно Web-сервис — задайте переменную `PORT`,
бот сам поднимет health-страницу на этом порту.

### Установка библиотек не нужна

Скрипт при первом запуске **сам ставит** `aiogram`, `aiosqlite`, `aiohttp`.
В консоли будет:

```
📦 Встановлюю потрібні бібліотеки: aiogram>=3.13,<4, aiosqlite, aiohttp
   (це робиться лише один раз, зачекайте 10–60 секунд)
✅ Бібліотеки встановлено.
```

Файл `requirements.txt` тоже лежит рядом — если хостинг умеет ставить сам,
он сделает это ещё до старта, и автоустановка просто пропустится.

## 🔄 Самоперезапуск каждые 6 часов

Работает **сам, без внешнего сторожа** — процесс перезапускает себя изнутри.
Поэтому это работает на любом хостинге.

- Данные **не теряются**: перед перезапуском база принудительно сбрасывается на диск
- Сообщений **никому не отправляется** — ни вам, ни клиентам
- В логе только служебная строка `Плановий перезапуск`

**Изменить интервал** — строка в начале файла:
```python
RESTART_EVERY_HOURS = 6      # 12 = раз в 12 часов, 0 = выключить
```
Или переменной окружения: `RESTART_HOURS=12`

## 💾 Как теперь защищены данные

| Механизм | Что даёт |
|---|---|
| **WAL** (`journal_mode=WAL`) | Запись не пропадает даже при `kill -9` и отключении питания |
| **`synchronous=FULL`** | Каждое сохранение физически пишется на диск, а не в буфер |
| **Checkpoint при остановке** | Перед выключением и перезапуском база дозаписывается |
| **Автобэкап раз в час** | 3 копии по кругу: `eurotour.db.bak0/1/2` |
| **Идемпотентный старт** | Повторный запуск не сбрасывает ваши тексты к заводским |
| **UPSERT пользователей** | Одновременные `/start` не вызывают ошибку БД |

**Проверено:** процесс убивали `kill -9` во время записи — пользователи,
обращения и отредактированные тексты уцелели (`test_persistence.py`, 18/18).

## 🖥 Свой сервер (VPS) — надёжнее всего

```bash
# 1. залить файл и поставить зависимости
pip install "aiogram>=3.13,<4" aiosqlite

# 2. создать сервис
sudo nano /etc/systemd/system/eurotour.service
```

```ini
[Unit]
Description=EUROTOUR Support Bot
After=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/eurotour
Environment="DB_PATH=/opt/eurotour/data/eurotour.db"
ExecStart=/usr/bin/python3 /opt/eurotour/s.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now eurotour
sudo journalctl -u eurotour -f     # логи
```

## ✅ После первого запуска

1. Напишите боту `/start` — увидите меню и кнопку **⚙️ Панель**
2. `⚙️ Налаштування → 📥 Змінити чат` → перешлите сообщение из рабочей группы
3. `🧪 Тест` — убедитесь, что обращения доходят
4. `📄 Розділи` — отредактируйте тексты под себя

Все правки сохраняются в базу и **переживают перезапуск**.
