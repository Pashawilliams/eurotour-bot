# 🚌 EUROTOUR Support Bot

Телеграм-бот поддержки со скрытой админ-панелью. Один файл, aiogram 3, SQLite.
**150/150 тестов пройдено.**

---

## ⚡ Быстрый старт

**Шаг 1.** Установите библиотеки:
```bash
pip install "aiogram>=3.13,<4" aiosqlite
```

**Шаг 2.** Откройте `bot.py`, в самом начале файла найдите строку и вставьте токен:

```python
TOKEN = ""          # ← ВСТАВТЕ СЮДИ ТОКЕН від @BotFather
```

Должно получиться так:

```python
TOKEN = "8154302197:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw"

ADMIN_ID = 7906546417   # ← ваш Telegram ID
```

**Шаг 3.** Запустите:
```bash
python3 bot.py
```

Всё. База создастся сама при первом запуске.

> **Где взять токен:** Telegram → [@BotFather](https://t.me/BotFather) → `/newbot`
> (или `/mybots` → выберите бота → API Token). Скопируйте строку и вставьте между кавычками.
>
> ⚠️ Токен — это пароль от бота. Никому его не показывайте и не выкладывайте в публичный репозиторий.

Если токен не вставлен, бот при запуске сам подскажет, что и куда вписать.

## 🔑 Настройки в начале файла

| Параметр | Что это |
|---|---|
| `TOKEN` | Токен от [@BotFather](https://t.me/BotFather) — **обязательно** |
| `ADMIN_ID` | ID владельца, только он видит панель (уже стоит `7906546417`) |

Опционально то же самое можно задать переменными окружения — они имеют приоритет
над значениями в файле: `BOT_TOKEN`, `OWNER_ID`, `DB_PATH`, `LOG_LEVEL`.

## 📋 Первая настройка (5 минут)

1. **Создайте бота** у @BotFather → скопируйте токен.
2. **Запустите** бота: `BOT_TOKEN=... python3 bot.py`.
3. Напишите боту `/start` — вы увидите меню, а под ним кнопку **⚙️ Панель**
   (её видите только вы).
4. **Создайте группу** для обращений, добавьте туда бота.
5. В панели: `⚙️ Налаштування → 📥 Змінити чат` → **перешлите** в бота любое
   сообщение из этой группы. ID подставится сам.
6. Нажмите `🧪 Тест` — в группу придёт проверочное сообщение.
7. `📄 Розділи` → отредактируйте тексты «Про нас» и «Зв'язок» под себя.

Готово. Дальше всё меняется из панели без программиста.

## 🔌 Защита соединения — 3 уровня

Бот спроектирован так, чтобы **не отключаться** ни при каких сбоях.

### Уровень 1 — авто-переподключение (внутри кода)

Обрыв интернета, `502` от Telegram, таймаут — бот **не падает**, а переподключается
сам. Задержка растёт постепенно (5 → 10 → 15 … до 60 с), чтобы не долбить сервер.

```
🌐 Проблема зі звʼязком (TelegramNetworkError). Перепідключення через 5 с…
```

### Уровень 2 — watchdog (внутри кода)

Опаснее обрыва — «тихое зависание», когда процесс жив, но обновления не приходят.
Каждую минуту watchdog проверяет: если от Telegram **тишина дольше 3 минут**, он
делает контрольный запрос. Не ответили 3 раза подряд → процесс перезапускается.

```
watchdog: Telegram не відповідає (3/3) → перезапуск процесу
```

### Уровень 3 — внешний сторож `run.sh`

Если процесс всё-таки умер (нехватка памяти, `kill`, сбой системы) — сторож
поднимает его за 5 секунд. Плюс:

- **`flock`-блокировка** — вторая копия физически не запустится
  *(две копии на одном токене = главная причина «бот не отвечает»)*
- **автоустановка** `aiogram`/`aiosqlite`, если их нет
- **снятие webhook** перед стартом
- **ротация лога** при достижении 5 МБ

**Запуск с полной защитой:**
```bash
bash run.sh
```

### Что ещё сделано

| Проблема | Решение |
|---|---|
| Ошибка в одном обработчике роняла бота | Глобальный перехватчик — polling продолжается |
| Лог засорялся трейсбеками | «Безобидные» ошибки (`query is too old`, `message is not modified`) гасятся одной строкой |
| Превышение лимита Telegram | `TelegramRetryAfter` — бот ждёт нужное время и продолжает |
| Две копии конфликтовали | Определяется явно, с понятным сообщением в лог |
| Бот «висел» при остановке | Корректное завершение по `SIGINT`/`SIGTERM` |

**Проверено тестами:** `python3 test_resilience.py` — 16/16.
Тесты эмулируют обрыв сети, конфликт копий, зависание и падение процесса.

## 🖥 Запуск 24/7 на сервере (systemd)

`/etc/systemd/system/eurotour.service`:

```ini
[Unit]
Description=EUROTOUR Support Bot
After=network-online.target

[Service]
Type=simple
User=eurotour
WorkingDirectory=/opt/eurotour
Environment="BOT_TOKEN=ваш_токен"
Environment="OWNER_ID=7906546417"
ExecStart=/usr/bin/python3 /opt/eurotour/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now eurotour
sudo journalctl -u eurotour -f      # смотреть логи
```

**Бэкап базы:**
```bash
0 4 * * * cp /opt/eurotour/eurotour.db /opt/backups/eurotour_$(date +\%F).db
```
Плюс встроенная выгрузка конфигурации: `⚙️ Панель → 💾 Бекап`.

## ❓ Частые вопросы

**Бот не пишет в группу.** Убедитесь, что бот добавлен в группу. Если группа —
супергруппа с топиками, у бота должны быть права на отправку. Проверьте `🧪 Тест`.

**Как узнать свой ID?** Команда `/myid` — она доступна только админам.

**Как добавить менеджера?** `👮 Адміни → ➕ Додати` → перешлите сообщение от него
или введите ID. Роль «только обращения» даст доступ к заявкам, но не к текстам и рассылкам.

**Бот не может написать менеджеру в личку.** Ограничение Telegram: пользователь
должен сам первым нажать `/start` у бота. Поэтому для заявок используется группа.

**Изменения применяются сразу?** Да, перезапуск не нужен — всё хранится в базе.
