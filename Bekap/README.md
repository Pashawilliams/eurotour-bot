## Можливості бота (на момент архіву)

- 🌍 **4 мови:** українська, російська, польська, англійська
- 🔄 **Автопереклад** правок: текст лягає у свою мову, решта перекладається сама
- 🖼 **Галерея медіа:** необмежена кількість фото/відео, показ альбомами по 10
- 📨 **Звернення:** доставка у груповий чат і/або особисто адмінам (вимикається)
- ✍️ **Відповіді клієнтам** — з панелі та прямо з групи
- 🗑 **Видалення звернень** — поштучно, вибором галочками або всі за статусом
- 👮 **Ролі:** власник · повний доступ · менеджер (лише відповіді)
- 💾 **Збереження даних:** WAL + автобекап + запис у гілку `bot-data` кожні 5 хв
- 🔁 **Самоперезапуск** кожні 6 годин без втрати даних

## Як відновитися з цього архіву

1. Скопіювати `Bekap/kod/s.py` у корінь репозиторію.
2. Скопіювати `Bekap/workflows/*.yml` у `.github/workflows/`.
3. Базу `Bekap/baza/eurotour.db` завантажити у гілку `bot-data` як `data/eurotour.db`.
4. Перевірити секрети: `BOT_TOKEN`, `OWNER_ID`.
5. Запустити workflow **EUROTOUR bot** вручну (Actions → Run workflow).

> Токен у `Bekap/kod/s.py` навмисно порожній — він береться з секрету `BOT_TOKEN`.
